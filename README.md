# Privacy Policy

Questa applicazione è uno strumento privato sviluppato al solo scopo di automatizzare la pubblicazione di contenuti visivi sul profilo Pinterest dell'autore.

Raccolta Dati: L'applicazione non raccoglie, memorizza, traccia o condivide alcun dato personale di utenti terzi.

Uso dei Dati: Gli unici dati elaborati sono i token di autenticazione API necessari per inviare immagini e descrizioni al profilo Pinterest dell'utente proprietario.

Contatti: Per qualsiasi domanda, contattare me
